# EmpleoRED

1.PLANTEAMIENTO DEL PROBLEMA:

En el municipio de Ocaña, Norte de Santander, EmpleoRed plantea la necesidad de
facilitar el acceso a oportunidades laborales para personas mayores de 18 años que buscan
empleo o desean mejorar su situación laboral. El proyecto propone centralizar en un sistema
web la presentación de perfiles profesionales, habilidades, experiencias, talentos y proyectos,
y facilitar el contacto con posibles empleadores.
Entre las posibles causas que se investigarán se encuentran la dispersión de la
información sobre oportunidades laborales, las dificultades para dar visibilidad a las
competencias de los candidatos y la falta de herramientas digitales que faciliten el encuentro
entre quienes buscan empleo y quienes necesitan contratar personal. Estas causas son
hipótesis de trabajo y deberán validarse mediante consulta a candidatos y empleadores de
Ocaña.
Como consecuencia potencial, algunas personas podrían tener dificultades para dar a
conocer sus capacidades y encontrar oportunidades acordes con su perfil, mientras que los
empleadores podrían invertir tiempo en localizar candidatos que respondan a sus
necesidades. No se dispone todavía de datos de campo que permitan establecer la magnitud
de estas situaciones.
Por esta razón, se propone desarrollar EmpleoRed, un sistema web que permita
registrar usuarios, crear perfiles profesionales, publicar talentos, consultar ofertas laborales,
gestionar postulaciones y facilitar la búsqueda de candidatos. La plataforma busca centralizar
información y mejorar la conexión entre candidatos y empleadores de Ocaña.

2.DESCRIPCIÓN DEL PROYECTO

EmpleoRed será un sistema web de empleabilidad dirigido a personas mayores de 18
años de Ocaña, Norte de Santander, que deseen presentar sus habilidades, experiencia,
proyectos o talentos, así como a empresas y personas que requieran encontrar candidatos. El
sistema integrará una interfaz de usuario (frontend), una lógica de negocio y servicios de
aplicación (backend), y una base de datos para almacenar la información de usuarios, perfiles,
talentos, ofertas y postulaciones.
Los candidatos podrán crear y administrar su perfil, publicar sus talentos, adjuntar
documentos permitidos, consultar ofertas y postularse. Los empleadores podrán crear su
perfil, publicar y administrar ofertas, buscar talentos y revisar postulaciones. El administrador
